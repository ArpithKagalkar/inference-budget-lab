BUILT TO BE SCRUTINIZED

Know what you are measuring.

A useful optimization is one you can reproduce and explain.

01 / OBSERVE

Normalize before diagnosing

InferenceOps imports JSON or Langfuse-exported records into a strict trace contract. Missing data remains unknown. Demo traces are deterministic and always labelled synthetic.

02 / DETECT

Rules before prose

Oversized-model, repeated-prompt, and excessive-RAG findings are calculated from trace evidence. Estimated potential is not described as verified savings.

03 / EXPERIMENT

Calibrate, freeze, evaluate

Routing thresholds are selected on validation data, frozen, then measured on held-out requests. Cost, quality, p95 latency, error rate, and incomplete accounting determine eligibility.

04 / REAL MODELS

Simulation is not model evidence

Ollama and OpenAI-compatible endpoints provide real calls. Hosted runs require worst-case spend preflight, an explicit typed confirmation, and request-level budget reservation.

05 / CONTROL

Preview, constrain, verify

Only verified model-routing experiments may prepare changes. GitHub writes are restricted to a dedicated demo repository and two allowlisted paths. Pull requests are always drafts.

06 / LIMITS

No production claims yet

V1 does not merge, deploy, shadow traffic, or perform rollback. Slack stays staged without an explicit webhook confirmation. Production value requires independent labels and canary evidence.
